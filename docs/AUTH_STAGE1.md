# Авторизация: этап 1 — совместимый фундамент

Добавлены отдельные модели CabinetOwner и CabinetPosition. Владелец может иметь несколько позиций; одна позиция принадлежит одному владельцу. primary_partner_id фиксирует исходную позицию, но не определяет права администратора и не выбирает активную позицию.

Текущий вход не переключён: AuthService, AuthSession, AuthChallenge, API, cookie, регистрация, роли и существующие контакты остаются без изменений. Новые таблицы пока не являются источником полномочий. Совпадение email или телефона не даёт права объединять владельцев.

Существующая таблица users не изменяется. Этот этап не вводит вторую действующую систему входа: cabinet_owners пока является только идентификатором владения, без пароля и контактов. Выбор дальнейшего использования users требует отдельной проверки её потребителей.

Создание таблиц: create_cabinet_schema(engine) из database.cabinet_migration, только с явно переданным движком. Первичное заполнение: backfill_cabinet_owners(session), только с явно переданной сессией. Функция не делает commit; решение о commit или rollback принимает вызывающий код. Число в результате — количество новых владельцев. Повторный запуск пропускает уже связанные позиции.

Никакого CLI, автоматического запуска миграции или подключения к рабочей базе этот этап не добавляет. Проверять сначала на отдельной копии, без конкурентной регистрации. Новые модели намеренно не подключены к штатному startup; изменение импорта, а следовательно и регистрации таблиц в Base, будет отдельным этапом.

Запись файлов в GitHub не означает, что миграция выполнена или тесты прошли. Целевой новый набор: tests/test_cabinet_ownership.py. Затем необходима регрессия авторизации, моделей и административного доступа. Рабочую базу не мигрировать без отдельного решения.

Следующие этапы: подтверждённые контакты владельца; перевод кодов и сессий; безопасная проверка принадлежности и выбор позиции; совместимость старых сессий; интеграция регистрации. Открытие дополнительных позиций для пользователей пока не включается.
