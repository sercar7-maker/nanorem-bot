# 🚀 START HERE — NANOREM MLM BOT

## 📌 Что это

MLM Telegram бот с:
- партнёрской системой
- рангами (Silver / Gold)
- оборотом
- комиссионными
- реферальной системой

---

## ⚡ Быстрый старт

1. Установить зависимости:

pip install -r requirements.txt

2. Запустить:

python main.py

---

## ⚠️ Важно (частая проблема)

Если ошибка:

127.0.0.1:12334

Решение:

set HTTP_PROXY=
set HTTPS_PROXY=

## 📂 Основные файлы

- main.py — запуск бота
- tg_handlers/ — Telegram логика
- services/ — бизнес-логика
- database/ — модели и БД
- scheduler/ — фоновые задачи
