# Критическая проблема (решена)

## Симптомы

* TLS ошибки:

  * CERTIFICATE_VERIFY_FAILED
  * EOF
  * ConnectTimeout
* httpx не работает
* Telegram бот не запускается
* в логах:

  * 127.0.0.1:12334

---

## Причина

Hiddify в режиме:

👉 **Системный прокси**

```text
127.0.0.1:12334
```

Перехватывает ВСЕ соединения и ломает TLS для httpx.

---

## Почему requests иногда работал

* использует другой стек
* иногда обходил проблему

---

## Почему httpx падал

* stricter TLS
* не принимает разорванные соединения

---

# Решение

## ❌ Нельзя

* использовать Hiddify в режиме "Системный прокси"

---

## ✅ Нужно

### Вариант 1 (рекомендуется)

Hiddify:

```text
VPN (Экспериментальный)
```

---

### Вариант 2

Использовать альтернативный VPN:

* PlanetVPN (используется сейчас)

---

## Дополнительно (в коде)

В `tg_handlers/bot.py`:

```python
import os

os.environ["NO_PROXY"] = "*"

for key in [
    "HTTP_PROXY", "HTTPS_PROXY", "ALL_PROXY",
    "http_proxy", "https_proxy", "all_proxy"
]:
    os.environ.pop(key, None)
```
