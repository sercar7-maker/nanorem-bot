### Обнаруженная проблема

Реферальная ссылка отображается как:

https://t.me/nanorem_bot?start=None

Причина:

в базе данных у партнёра отсутствует значение

telegram_link_code

---

### Что нужно проверить

Таблица:

Partner

Поле:

telegram_link_code

Если значение равно NULL или None, ссылка формируется неправильно.

---

### План исправления

Сделать автоматическую генерацию telegram_link_code при создании партнёра.

Пример генерации:

```python
import uuid
telegram_link_code = str(uuid.uuid4())[:8]
```
