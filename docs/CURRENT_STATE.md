---

# Telegram функции

Работают:

👤 Профиль  
- показывает ID  
- дату регистрации  
- текущий ранг (Silver / Gold)

💰 Баланс  
- считается из таблицы Commission  

👥 Моя сеть  
- показывает структуру сети до 5 уровней  
- общее количество партнёров  

🔗 Реферальная ссылка  
- формируется из telegram_link_code  

📊 Статистика  
показывает:

- количество партнёров  
- сумму комиссий  
- баланс  
- личный оборот за месяц  
- оборот сети за месяц  

🌐 Сайт  
- ссылка на https://nanorvs.ru

# Rank System (карьерная система)

Реализовано:

- Silver  
- Gold  

Логика:

- расчёт ранга через RankService  
- авто-повышение при достижении оборота  
- ранг отображается в профиле  

⚠️ Проблема:

- уведомление о повышении ранга пока не отправляется (async issue)

# Orders / Оборот

Работает частично:

- личный оборот считается  
- сетевой оборот пока не реализован

# Database

Используется:

SQLite  
SQLAlchemy  

Основные таблицы:

Partner  
Purchase  
Commission  
Balance  
Withdrawal  

Поле lineage хранит цепочку аплайнов партнёра.

Пример:

Partner 10  
lineage [2,5]  

Это означает:

2 → 5 → 10
